项目介绍

BigOrange 是以全屏沉浸式歌词播放为核心的在线音乐播放器，支持网易云、Navidrome 和本地音乐库。功能包括智能歌词匹配、AI 生成配色主题、多种全屏歌词动画。界面语言为中文和英文。提供 Electron 桌面端版本（Windows、macOS、Linux）与基于 Node.js 的 Web 版本。

相对于上游修复的内容

只保留网易云音源，移除酷狗、QQ、波点。
只保留中文和英文，移除印尼语。
应用名、数据目录、桌面文件改为 BigOrange。
AppImage 默认走系统 GPU，不再强制软渲染。
