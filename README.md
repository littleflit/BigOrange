项目介绍

BigOrange 者，沉浸式歌词之音乐播放器也。支持网易云、Navidrome 及本地曲库，有智能歌词匹配、AI 配色、全屏歌词动画之能。言有中英二种。分桌面端（Windows、macOS、Linux）与网页端，可多处部署。

与上游之异

但留网易云一源，去酷狗、QQ、波点。
但留中英二语，去印尼语。
应用之名、数据之目录、桌面之文件，皆改为 BigOrange。
AppImage 默认用系统 GPU，不再强制软渲染。
